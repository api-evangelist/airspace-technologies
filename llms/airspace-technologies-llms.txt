# Airspace Technologies

> Airspace is a time-critical logistics provider offering AI-powered shipping (Next Flight Out, on-demand ground, charter, and specialty services) across 80+ countries. Its public V3 REST API supports Order Creation, Quote Generation, and Active Shipment Monitoring, with asynchronous processing delivered over webhooks.

## APIs
- [Airspace API Documentation (V3)](https://api.airspace.com/api-docs/v3): Current asynchronous REST API — orders, quotes, events, invoices, piece libraries, address books.
- [Airspace API Documentation (V2)](https://api.airspace.com/api-docs/v2): Prior REST API version.
- [API Docs portal](https://api.airspace.com/api-docs/): Version index (V2, V2 beta, V3).

## Specs
- [V3 OpenAPI](openapi/airspace-technologies-v3-openapi.json): OpenAPI 3.0.1, 17 operations, bearer auth.
- [V2 OpenAPI](openapi/airspace-technologies-v2-openapi.json): OpenAPI 3.0.1, 16 operations.
